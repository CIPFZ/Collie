**方案 A `collie-icon-a.png`** — 几何化边境牧羊犬头部剪影
正面隐喻，辨识度高，适合做品牌吉祥物与社交头像。

抽象隐喻，直接表达「串行推进 + 一个引导者」这一核心设计，
几何简洁，16px 下必然清晰。
