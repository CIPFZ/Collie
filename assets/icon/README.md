## 定稿方案

**方案 A `collie-icon-a.png`** — 几何化边境牧羊犬头部剪影
深岩蓝与暖白构成的侧面犬头，琥珀色单眼点出「守望」意味。
正面隐喻，辨识度高，可直接延伸为品牌吉祥物与社交头像。

待验证：16px / 32px 下犬头细节的清晰度。若实测发现糊，
处理方式为「小尺寸专用简化版」（减少耳部与颈部切面），而非更换方案。
